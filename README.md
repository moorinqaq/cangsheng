# 苍生之下 · 六派设定集

> 井底有光封未启，人间无梦不曾收。

一个中式玄幻世界观的可视化设定站。六大门派、众生炉、祟与六派之外——灵力不是天上掉的，是从凡人身上收上来的。

**线上地址：** <https://xingmilu.xyz>

---

## 这是什么

《苍生之下》的世界观设定集，被做成了一个单页网站。

- **世界观** — 三层天地（上苍 / 六域 / 凡境），一条灵机循环
- **故事背景** — 灵潮、六脉、众生炉、八百年、第七脉
- **六大门派** — 寰裳殿 / 朝颂山庄 / 青墨峰 / 苍琼堂 / 青鸾峰 / 佛寺，每派含信条、四派系、地理建筑、两流派六维、技能表、人物关系
- **祟** — 众生炉底的怨，无实体与有实体两种
- **六派之外** — 散修、小门派，与三条不被承认的路

## 技术说明

纯静态，无构建步骤，无依赖。

```
index.html          单页（hash 路由：#huan 直达寰裳殿）
404.html            Cloudflare Pages 自定义 404
_headers            缓存与安全响应头
assets/
  style.css         全部样式
  app.js            世界观数据 + 渲染逻辑（原生 JS，无框架）
  art/              概念图与元素图（36 张）
    prompts.md      出图提示词存档
```

- 字体：微软雅黑 / 苹方（无衬线）
- 概念图：AI 生成（火山方舟 Seedream 5.0），纯黑底抠透明后使用
- 元素图：六派各一枚，用于「六解」悬停

## 本地预览

直接双击 `index.html` 即可，或：

```bash
python -m http.server 8000
```

## 部署

托管在 Cloudflare Pages，域名走 Cloudflare DNS。

```bash
wrangler pages deploy . --project-name=xingmilu --branch=main
```

推送 `main` 分支不会自动部署（未接 CI），需要手动执行上面的命令，或直接在 Cloudflare Pages 面板上传。
